# Roadmap после тестового

## P0 — надёжность

- PostgreSQL adapter;
- durable queue;
- distributed rate limit;
- OpenTelemetry;
- source snapshots;
- admin-only generation;
- automated DB backup;
- integration tests с mocked HTTP server.

## P1 — качество фактов

- NER model;
- negation detector;
- claim extraction;
- NLI entailment score;
- sensitive-topic guard;
- per-language extractors;
- human review queue.

## P2 — продукт

- category filters;
- search;
- saved mood preference;
- language choice;
- shareable comparison card;
- source freshness SLA;
- article history;
- accessible diff highlighting.

## P3 — evaluation

- permanent golden dataset;
- model/prompt experiment registry;
- semantic review labels;
- regression dashboard;
- cost/quality Pareto chart;
- automated canary before prompt/model rollout.

## Не делать без доказанной необходимости

- autonomous news generation;
- full-page scraping of arbitrary sites;
- personalized political persuasion;
- hidden emotional framing;
- confidence numbers generated by the same LLM;
- real-time streaming architecture для небольшого RSS feed.
